# authentik_certificate_key_pair_generated (Resource)

Certificate-key pair generated by authentik itself. The private key never leaves authentik, so it is not stored in the Terraform state or plan. To rotate it, change any of the arguments that force a new resource, or replace it with `-replace`/`replace_triggered_by`.

## Example Usage

```terraform
# Have authentik generate a certificate-key pair, e.g. to sign OAuth2 tokens
# (`signing_key` on `authentik_provider_oauth2`). The private key stays in
# authentik and never reaches the Terraform state.

resource "authentik_certificate_key_pair_generated" "signing" {
  name          = "oauth2-signing"
  common_name   = "oauth2-signing-2026"
  validity_days = 730
}
```
